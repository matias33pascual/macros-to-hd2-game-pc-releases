# Macros to HD2 Game PC — Downloads

**Download for Windows (latest version):**
https://github.com/matias33pascual/macros-to-hd2-game-pc-releases/releases/latest/download/MacrosToHD2Game-PC-Windows.zip

1. Download the zip and extract it to a folder.
2. Open `Macros to HD2 Game PC.exe`.
3. If Windows asks about the firewall, allow access so your phone can connect.
4. Follow **Getting started** inside the app.
