# Macros to HD2 Game PC — Descargas

**Descargar para Windows (última versión):**
https://github.com/matias33pascual/macros-to-hd2-game-pc-releases/releases/latest/download/MacrosToHD2Game-PC-Windows.zip

1. Descargá el zip y extraelo en una carpeta.
2. Abrí `Macros to HD2 Game PC.exe`.
3. Si Windows pregunta por el firewall, permití el acceso para que el celular se pueda conectar.
4. Seguí **Cómo empezar** dentro de la app.

App para Android: [Google Play](https://play.google.com/store/apps/details?id=com.macros.helldivers)

Este repositorio solo contiene los releases; no tiene código.
